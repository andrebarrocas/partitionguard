# PartitionGuard 0.2.0 candidate

This candidate adds measured workload limits, bounded-memory verification,
authenticated reviewer receipts for a controlled runner, private SQLite
snapshots, and a reproducible support/upgrade matrix.

- [Workload measurements and limits](../workload-limits.md)
- [Controlled approvals and evidence handling](../controlled-approvals.md)
- [Supported environments and upgrade procedure](../supported-environments.md)
- [Validation results](../validation.md)

0.1.0 → 0.2.0 recovery is rehearsed with the same adapter versions and original
baseline on DuckDB, PostgreSQL and local Delta. Unknown ledger versions are
rejected. Keep the original snapshot and runner available while upgrading.

Publication, independent security sign-off, deployment provisioning and the
production pilot remain separate gates. Source writers must remain frozen
during the bounded additive migration.
