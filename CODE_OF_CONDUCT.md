# Community code of conduct

PartitionGuard welcomes people with different backgrounds, abilities, experience levels, and viewpoints. Participation includes issues, code review, discussions, documentation, and project events.

Be respectful and specific. Critique ideas and code without attacking people. Make room for questions, acknowledge mistakes, and help others understand decisions. Disagreement is expected; harassment is not.

Unacceptable behavior includes threats, discriminatory abuse, sexual harassment, repeated personal attacks, publishing another person's private information without consent, and sustained disruption after a request to stop. Retaliation against someone who reports a concern is also unacceptable.

Maintainers may edit or remove harmful content, pause a conversation, require an apology or behavioral change, restrict participation temporarily, or remove a participant for serious or repeated violations. Decisions should be proportionate and explained privately where possible. A maintainer involved in a complaint should not decide its outcome alone when another uninvolved maintainer is available.

To report a concern, use a private contact published by the repository owner. Do not post identifying details in a public issue. Before accepting a public contributor community, the repository owner must publish that contact and designate a reviewer; this initial unpublished repository does not invent a staffed reporting address or response-time guarantee.

Reports should contain only the information needed to understand and respond to the incident. Maintainers should limit access to that information, protect reporters from retaliation, and consider a request for reconsideration when new evidence is available.

This is an independently written project policy.
